# Provider Ecosystem

Convey provides **88+ built-in provider adapters** across 5 primary communication channels. All adapters include automatic circuit breakers, retry backoffs, and scorecards.

## Dynamic Routing Strategies

When dispatching messages, you can select one of four autonomous routing strategies:

1. **`SMART_SCORECARD`** (Default):
   Calculates a real-time weight score based on $70\% \text{ Delivery Rate} + 20\% \text{ Latency SLA} + 10\% \text{ Unit Cost}$. Traffic automatically routes away from degraded providers.
2. **`PRIMARY_FALLBACK`**:
   Attempts delivery through the primary provider. If the request encounters a 5xx error or rate limit (429), it immediately falls back through the ordered `fallbackChain`.
3. **`LEAST_COST`**:
   Selects the lowest rate-card provider for the recipient's country code and currency.
4. **`ROUND_ROBIN`**:
   Distributes traffic uniformly across all healthy configured providers.

## Zero-Cost Mock Sandbox Mode

For testing without incurring carrier charges or configuring API credentials, enable the Mock Sandbox provider:

```json
{
  "routing": {
    "strategy": "PRIMARY_FALLBACK",
    "fallbackChain": ["mock-sandbox"]
  }
}
```

The mock provider immediately simulates realistic carrier delivery receipts (DLR) with 99.8% success rates.
