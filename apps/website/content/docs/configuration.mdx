# Configuration Reference

Convey uses environment variables for all operational tuning. You can specify variables in `.env` or inject them directly via Kubernetes ConfigMaps and Secrets.

---

## Core Server & Network Configuration

| Variable | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `PORT` | `number` | `3000` | HTTP port for Elysia.js server |
| `HOST` | `string` | `0.0.0.0` | Bind IP interface |
| `NODE_ENV` | `string` | `development` | Runtime environment (`development`, `production`, `test`) |
| `LOG_LEVEL` | `string` | `info` | Structured logging verbosity (`debug`, `info`, `warn`, `error`) |
| `CORS_ORIGIN` | `string` | `*` | Allowed CORS origins for browser web apps |

---

## Database Configuration (PostgreSQL 18)

| Variable | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `DATABASE_URL` | `string` | `postgresql://convey:convey@localhost:5432/convey` | PostgreSQL 18 connection string |
| `DB_POOL_MIN` | `number` | `5` | Minimum connection pool size |
| `DB_POOL_MAX` | `number` | `25` | Maximum connection pool size |
| `DB_IDLE_TIMEOUT_MS` | `number` | `30000` | Idle connection timeout in milliseconds |
| `DB_STATEMENT_TIMEOUT_MS`| `number`| `5000` | Maximum SQL statement execution timeout |

### Database Migrations

Convey uses Drizzle ORM models and one canonical pre-release SQL baseline:

```bash
# Validate the canonical CREATE definitions
bun run db:check

# Initialize an empty database with the current baseline
bun run db:migrate
```

## Cryptography & Zero-Trust Security

| Variable | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `PAYLOAD_ENCRYPTION_KEY` | `string` | **Production** | Unique high-entropy secret of at least 32 characters |
| `PAYLOAD_ENCRYPTION_KEYS` | `string` | Optional | JSON object mapping integer key versions to secrets |
| `PAYLOAD_ENCRYPTION_KEY_VERSION` | `integer` | `1` | Active version from the configured ring |

### Generating an encryption secret

```bash
openssl rand -hex 32
```

### Key rotation

Deploy the complete key ring to every process before selecting the new active version. Retain previous encryption keys until their ciphertext and backups have expired. Unknown versions fail closed. There is no automatic re-encryption command.

### Pre-release database changes

Convey has not had its first release. Update complete CREATE definitions in the canonical schema, validate with `bun run db:check`, and initialize a fresh disposable database with `bun run db:migrate`. The initializer rejects changed baselines without modifying existing data. Do not add upgrade-only ALTER patches or compatibility readers for old development records. Freeze the baseline and introduce forward migrations at the first release.
