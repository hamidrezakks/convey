# Welcome to Convey

**Convey** is a standalone communication service built with Bun, Elysia, PostgreSQL 18, and BullMQ on a Redis-compatible store. It accepts messages durably, then processes delivery asynchronously through configured provider adapters. The repository also includes a web console, optional plugins, TypeScript/Python/Go SDKs, and an independent Go recipient gateway.

<Callout type="info" title="Pre-release candidate">
  Current qualification targets one regional deployment and uses mock providers. HTTP 202 means accepted work, not recipient delivery. Catalog entries and offline fixtures do not establish live-provider certification, a public SLA, geographic failover, or a compliance certification.
</Callout>

## Core Building Blocks

<Cards>
  <Card title="Durable Acceptance" href="/docs/architecture#fast-path-ingestion">
    Scoped idempotency reservations and a PostgreSQL message/outbox transaction precede asynchronous dispatch.
  </Card>
  <Card title="Encrypted Payload Storage" href="/docs/architecture#zero-trust-encryption">
    AES-256-GCM protects stored recipient handles and payloads. Operators own key management and recovery.
  </Card>
  <Card title="Dispatch Scheduling" href="/docs/architecture#fairness-scheduler">
    Workers combine priority, tenant scheduling, configured routing, and bounded retries.
  </Card>
  <Card title="Go Recipient Gateway" href="/docs/gateway">
    Send a userId to resolve missing delivery addresses from your customer service before forwarding to Convey.
  </Card>
</Cards>
