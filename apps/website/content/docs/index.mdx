# Welcome to Convey

**Convey** is a standalone, ultra-high-throughput communication gateway and notification infrastructure built natively on **Bun 1.4**, **Elysia.js**, **PostgreSQL 18**, and **DragonflyDB**.

It provides synchronous sub-15ms message ingestion acceptance, zero-trust AES-256-GCM envelope encryption at rest, a Deficit Round Robin multi-tenant scheduler, an autonomous WhatsApp 24h session cost autopilot, and 88+ turnkey provider adapters.

<Callout type="info" title="Zero External Vendor Lock-in">
  Convey is completely self-contained with no external cloud SaaS dependencies. It compiles into a single binary deployment or Docker container with full observability.
</Callout>
