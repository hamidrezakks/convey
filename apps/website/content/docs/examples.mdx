# Integration Examples

Use these examples with a configured local or self-hosted server. Set `CONVEY_API_KEY` to an authorized credential and choose its team. The [SDK guide](/docs/sdks) explains local package setup; Convey has not yet had its first release.

## Send an SMS from TypeScript

```typescript
import { Channel, Convey, MessagePriority } from '@convey/sdk';

const client = new Convey({
  apiKey: process.env.CONVEY_API_KEY!,
  baseUrl: process.env.CONVEY_BASE_URL ?? 'http://localhost:3000',
  teamId: 'payments',
});

const accepted = await client.messages.send({
  channel: Channel.SMS,
  recipient: '+14155552671',
  content: { body: 'Your order 10928 is confirmed.' },
  priority: MessagePriority.HIGH,
  userId: 'customer-42',
  team: 'payments',
  category: 'transactional',
  country: 'US',
  idempotencyKey: 'order-10928-sms',
});

console.log(accepted.messageId, accepted.state);
```

The SDK converts this ergonomic request to `recipients.phone` and an SMS channel with `content.text`. Use a stable key tied to the logical send. The accepted message ID is an opaque `msg_` identifier; acceptance does not establish delivery.

## Inspect the raw delivery state

The server returns `state` and per-channel summaries. This example reads that response directly, avoiding current SDK status type differences:

```typescript
const response = await fetch(
  `${client.baseUrl}/v1/messages/${encodeURIComponent(accepted.messageId)}?include=timeline`,
  { headers: { Authorization: `Bearer ${process.env.CONVEY_API_KEY!}` } },
);

if (!response.ok) {
  throw new Error(`Status lookup failed: ${response.status}`);
}

const status = await response.json();
console.log(status.state, status.channels, status.timeline);
```

For sandbox messages, use the same sandbox-scoped key or include `X-Convey-Sandbox: true` in the lookup headers. The standalone timeline route is `/v1/messages/:messageId/timeline`; the trace route is `/v1/messages/:messageId/trace`.
