# Client Libraries & SDKs

Convey includes TypeScript/JavaScript, Python, and Go SDK source packages. The project is pre-release; package manifests and environment preset URLs do not establish a published release or hosted service. Use a local package or a release artifact you have validated, and point the client at your own deployment.

| Language | Repository package | Declared runtime |
| :--- | :--- | :--- |
| TypeScript / JavaScript | [`packages/sdk`](https://github.com/hamidrezakks/convey/tree/a2daf909f9deb825a29cb571bf18b9c3efd94008/packages/sdk) (`@convey/sdk`) | Node.js 18+ or Bun 1+ |
| Python | [`packages/sdk-py`](https://github.com/hamidrezakks/convey/tree/a2daf909f9deb825a29cb571bf18b9c3efd94008/packages/sdk-py) (`convey-sdk`) | Python 3.10+ |
| Go | [`packages/sdk-go`](https://github.com/hamidrezakks/convey/tree/a2daf909f9deb825a29cb571bf18b9c3efd94008/packages/sdk-go) | Go 1.22+ |

The SDKs include send normalization, retries, tracing, and HMAC signature helpers. Client APIs use ergonomic channel and priority enums; the server's [wire payload](/docs/api-reference) uses lowercase channel values, `recipients`, and `channels`.

## Use the local packages

From a repository checkout, install workspace dependencies and build the TypeScript SDK:

```bash
bun install
bun run --cwd packages/sdk build
```

Link the built `packages/sdk` directory into your consuming application as a local dependency. Install the Python package with `python -m pip install ./packages/sdk-py`. For Go, use a local module replacement for `github.com/hamidrezakks/convey/packages/sdk-go` pointing at your checkout's `packages/sdk-go` directory.

## TypeScript

```typescript
import { Channel, Convey, MessagePriority } from '@convey/sdk';

const client = new Convey({
  apiKey: process.env.CONVEY_API_KEY!,
  baseUrl: process.env.CONVEY_BASE_URL ?? 'http://localhost:3000',
  teamId: 'payments',
});

const accepted = await client.messages.send({
  channel: Channel.EMAIL,
  recipient: 'customer@example.com',
  userId: 'customer-42',
  team: 'payments',
  category: 'transactional',
  country: 'US',
  priority: MessagePriority.HIGH,
  idempotencyKey: 'order-10928-confirmation',
  content: { subject: 'Order confirmed', body: 'Your order is confirmed.' },
});

console.log(accepted.messageId, accepted.state);
```

`MessagePriority.HIGH` maps to the wire priority `transactional`; `DEFAULT` maps to `normal`, and `LOW` maps to `marketing`. The send response supplies `messageId`, `publicId`, and a lowercase `state`; these SDK aliases differ from the raw REST response. The TypeScript client requires an explicit `baseUrl`, environment preset, or `CONVEY_BASE_URL`.

## Python

```python
import os
from convey import Channel, Convey, MessagePriority

client = Convey(
    api_key=os.environ["CONVEY_API_KEY"],
    base_url=os.environ.get("CONVEY_BASE_URL", "http://localhost:3000"),
    team_id="payments",
)

accepted = client.messages.send(
    channel=Channel.EMAIL,
    recipient="customer@example.com",
    user_id="customer-42",
    team="payments",
    category="transactional",
    country="US",
    priority=MessagePriority.HIGH,
    idempotency_key="order-10928-confirmation",
    content={"subject": "Order confirmed", "text": "Your order is confirmed."},
)

print(accepted.message_id, accepted.state)
```

`AsyncConvey` exposes asynchronous resource methods; await `client.messages.send(...)` with the same request fields.

## Go

```go
package main

import (
    "context"
    "fmt"
    "os"

    "github.com/hamidrezakks/convey/packages/sdk-go"
)

func main() {
    client := convey.NewClient(os.Getenv("CONVEY_API_KEY"),
        convey.WithBaseURL("http://localhost:3000"),
        convey.WithTeamID("payments"),
    )
    accepted, err := client.Messages.Send(context.Background(), convey.SendMessageRequest{
        Channel: convey.ChannelEmail,
        Recipient: "customer@example.com",
        UserID: "customer-42",
        Team: "payments",
        Category: "transactional",
        Country: "US",
        Priority: convey.PriorityHigh,
        IdempotencyKey: "order-10928-confirmation",
        Content: &convey.MessageContent{
            Subject: "Order confirmed",
            Body: "Your order is confirmed.",
        },
    })
    if err != nil {
        panic(err)
    }
    fmt.Println(accepted.MessageID, accepted.State)
}
```

## Current integration limits

Use a team authorized by your key; setting `teamId` or `team_id` does not grant access. Retain an explicit idempotency key for an application-level retry of the same send. Acceptance is not delivery.

Some SDK status, trace, batch, and webhook event types still differ from current server responses. Bulk SDK normalization also does not retain all per-item REST error information. Use the [REST reference](/docs/api-reference) for wire shapes and inspect raw bulk outcomes when partial failures matter. Avoid relying on lifecycle polling or typed framework event routing until that contract is qualified for your SDK version.

For customer callbacks, follow the [webhook verification example](/docs/webhooks). It verifies the exact body and reads the server's `event`, `timestamp`, and `data` envelope.
