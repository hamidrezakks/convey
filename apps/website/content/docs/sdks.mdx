# Official Client Libraries & SDKs

Convey provides production-tested, zero-dependency client SDKs across **TypeScript/JavaScript** (Node.js, Bun, Edge runtimes), **Python** (Sync & Async), and **Go** with built-in connection pooling, exponential jittered retries, and W3C distributed tracing.

---

## Language SDK Matrix

| Language | Package / Module | Runtimes | Features |
| :--- | :--- | :--- | :--- |
| **TypeScript / JS** | `@convey/sdk` | Node.js 18+, Bun, Deno, Cloudflare Workers | Zero deps, ESM/CJS, Web Streams, Async iterators |
| **Go** | `github.com/hamidrezakks/convey/packages/sdk-go` | Go 1.22+ | Zero deps, HTTP/2 connection pooling, Generics |
| **Python** | `convey-sdk` | Python 3.10+ | Zero deps, Sync + Asyncio native, Type annotations |

### Initialization

```typescript
import { Convey } from '@convey/sdk';

const convey = new Convey({
  apiKey: process.env.CONVEY_API_KEY!, // e.g. 'sk_live_...' or 'sk_test_...'
  baseUrl: 'http://localhost:3000',    // Defaults to http://localhost:3000
  timeoutMs: 10000,                    // 10s request timeout
  maxRetries: 3,                       // Max exponential backoff attempts
  teamId: 'marketing-core',            // Optional default team boundary
});
```

## 2. Official Go SDK

The Go SDK (`packages/sdk-go`) provides zero external dependencies, thread-safe monotonic ULIDs, and high-performance HTTP transport pooling.

### Installation

```bash
go get github.com/hamidrezakks/convey/packages/sdk-go
```

### Initialization & Sending Messages

```go
package main

import (
	"context"
	"fmt"
	"os"
	"time"

	"github.com/hamidrezakks/convey/packages/sdk-go"
)

func main() {
	client := convey.NewClient(os.Getenv("CONVEY_API_KEY"),
		convey.WithBaseURL("http://localhost:3000"),
		convey.WithTimeout(10*time.Second),
		convey.WithMaxRetries(3),
	)

	// Send an omnichannel email
	res, err := client.Messages.Send(context.Background(), convey.SendMessageRequest{
		Channel:   convey.ChannelEmail,
		Recipient: "alex.doe@example.com",
		Priority:  convey.PriorityHigh,
		Content: &convey.MessageContent{
			Subject: "Your Monthly Statement",
			HTML:    "<p>Your monthly statement is ready for review.</p>",
		},
	})
	if err != nil {
		panic(err)
	}

	fmt.Printf("Accepted message: %s (Status: %s)\n", res.PublicID, res.Status)
}
```

### Go Auto-Pagination

```go
paginator := client.Suppressions.ListAutoPaging(&convey.ListSuppressionsQuery{
	Reason: convey.SuppressionHardBounce,
})

for {
	item, err := paginator.Next(context.Background())
	if err != nil {
		panic(err)
	}
	if item == nil {
		break // End of streaming results
	}
	fmt.Printf("Suppression: %s (%s)\n", item.Recipient, item.Reason)
}
```

## 3. Official Python SDK (`convey-sdk`)

The Python SDK provides both **Synchronous** (`Convey`) and **Asynchronous** (`AsyncConvey`) client engines with zero third-party dependencies.

### Installation

```bash
pip install convey-sdk
```

### Synchronous Usage

```python
import os
from convey import Convey, Channel, MessagePriority

client = Convey(
    api_key=os.environ["CONVEY_API_KEY"],
    base_url="http://localhost:3000",
    timeout=10.0,
    max_retries=3,
)

# Dispatch omnichannel message
response = client.messages.send(
    channel=Channel.EMAIL,
    recipient="alex@example.com",
    priority=MessagePriority.HIGH,
    content={
        "subject": "Security Alert: New Sign-in",
        "body": "<p>We detected a new sign-in to your account from San Francisco, CA.</p>",
    },
)

print(f"Accepted: {response.public_id} ({response.status})")
```

### Asynchronous Usage (FastAPI, Asyncio)

```python
import asyncio
import os
from convey import AsyncConvey, Channel, MessagePriority

async def main():
    client = AsyncConvey(api_key=os.environ["CONVEY_API_KEY"])

    # High-priority SMS OTP
    response = await client.messages.send(
        channel=Channel.SMS,
        recipient="+14155552671",
        priority=MessagePriority.CRITICAL,
        content={"body": "Your Convey verification code is: 489-201."},
    )

    print(f"Accepted SMS ID: {response.public_id}")

asyncio.run(main())
```

### Python Streaming Iterators

```python
# Synchronous streaming
for item in client.suppressions.list_auto_paging(limit=50):
    print(f"Suppressed: {item.recipient}")

# Asynchronous streaming
async for item in async_client.suppressions.list_auto_paging(limit=50):
    print(f"Suppressed: {item.recipient}")
```

## 4. Webhook Signature Verification

When Convey delivers webhook events, verify the HMAC-SHA256 signature using constant-time verification.

<Tabs items={['TypeScript / Node', 'Python', 'Go']}>
  <Tab value="TypeScript / Node">
```typescript
import { Convey, ConveySecurityError } from '@convey/sdk';

const isValid = await Convey.webhooks.verifySignature(
  rawPayload,
  signatureHeader,
  process.env.CONVEY_WEBHOOK_SECRET!,
);

// Or construct typed event
const event = await Convey.webhooks.constructEvent(
  rawPayload,
  signatureHeader,
  process.env.CONVEY_WEBHOOK_SECRET!,
);
```
  </Tab>

  <Tab value="Python">
```python
from convey import construct_webhook_event, verify_webhook_signature

# Verify signature bool
is_valid = verify_webhook_signature(
    raw_payload,
    signature_header,
    secret=os.environ["CONVEY_WEBHOOK_SECRET"],
)

# Or construct deserialized event
event = construct_webhook_event(
    raw_payload,
    signature_header,
    secret=os.environ["CONVEY_WEBHOOK_SECRET"],
)
print(f"Verified event {event.id}: {event.type}")
```
  </Tab>
