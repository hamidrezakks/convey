# Official Client Libraries & SDKs

Convey provides production-tested, zero-dependency client SDKs across **TypeScript/JavaScript** (Node.js, Bun, Edge runtimes), **Go**, and **Python** (Sync & Async) with built-in connection pooling, exponential jittered retries, client-side rate limiting, W3C distributed tracing, and lifecycle polling awaiters.

<Callout type="warn">
  **Strict Base URL Requirement**: Convey SDKs strictly require an explicit base URL or environment preset (`ConveyEnvironment.PRODUCTION`, `US`, `EU`, `STAGING`, `LOCAL`, `SANDBOX`, or `CONVEY_BASE_URL` env var). If no base URL is supplied, the SDK immediately throws `ConveyConfigurationError` to prevent misdirected communications.
</Callout>

### Initialization with Presets & Interceptors

```typescript
import { Convey, ConveyEnvironment } from '@convey/sdk';

const convey = new Convey({
  apiKey: process.env.CONVEY_API_KEY!,
  environment: ConveyEnvironment.PRODUCTION, // Canonical: https://api.convey.dev
  rateLimiter: { maxRequestsPerSecond: 100, maxBurst: 20 },
});

// Attach custom request/response interceptor
convey.use({
  name: 'tenant-tracer',
  onRequest: (ctx) => {
    ctx.headers['x-tenant-id'] = 'tenant_99';
    return ctx;
  },
  onResponse: (ctx) => {
    console.log(`[HTTP ${ctx.response.status}] took ${ctx.durationMs}ms`);
    return ctx;
  },
});
```

### Fluent Message Builder & Delivery Polling

```typescript
// 1. Fluent Builder Dispatch
const message = await convey
  .message()
  .to('alex.doe@example.com')
  .email({
    subject: 'Your Monthly Invoice #INV-2026-08',
    html: '<p>Hi Alex, your invoice of <strong>$149.00</strong> is ready.</p>',
  })
  .priority('HIGH')
  .team('finance')
  .send();

console.log(`Accepted: ${message.publicId}`);

// 2. Await Delivery Lifecycle
const deliveredMessage = await convey.messages.waitForDelivery(message.publicId, {
  pollIntervalMs: 500,
  timeoutMs: 30000,
});
console.log(`Delivered status: ${deliveredMessage.status}`);
```

### Webhook Framework Handlers

```typescript
// Next.js App Router (app/api/webhooks/convey/route.ts)
import { Convey } from '@convey/sdk';

const handler = Convey.webhooks.createHandler({
  secret: process.env.CONVEY_WEBHOOK_SECRET!,
  handlers: {
    'message.delivered': (event) => console.log('Delivered:', event.data.messageId),
    'message.failed': (event) => console.warn('Failed:', event.data.messageId),
  },
});

export async function POST(req: Request) {
  return handler.handleRequest(req);
}
```

### Initialization & Fluent Builder

```go
package main

import (
	"context"
	"fmt"
	"time"

	"github.com/hamidrezakks/convey/packages/sdk-go"
)

func main() {
	client := convey.NewClient("sk_live_...",
		convey.WithEnvironment(convey.EnvProduction),
		convey.WithRateLimiter(50, 10),
		convey.WithTimeout(10*time.Second),
	)

	// Fluent Message Builder
	resp, err := client.Messages.Builder().
		To("customer@example.com").
		Email("Order Update", "<p>Shipped!</p>").
		Priority(convey.PriorityHigh).
		Team("logistics").
		Send(context.Background())

	if err != nil {
		panic(err)
	}

	// Polling awaiter
	detail, err := client.Messages.WaitForDelivery(context.Background(), resp.PublicID,
		convey.WithPollInterval(500*time.Millisecond),
		convey.WithPollTimeout(30*time.Second),
	)

	fmt.Printf("Message status: %s\n", detail.Status)
}
```

### Webhook HTTP Handler (Standard `net/http`)

```go
func main() {
	handler := convey.NewWebhookHandler(os.Getenv("CONVEY_WEBHOOK_SECRET"), map[string]convey.WebhookEventHandler{
		"message.delivered": func(event *convey.WebhookEvent) error {
			fmt.Printf("Delivered: %s\n", event.ID)
			return nil
		},
	})

	http.HandleFunc("/webhooks/convey", handler)
	http.ListenAndServe(":8080", nil)
}
```

### Synchronous & Asynchronous Clients

```python
from convey import Convey, AsyncConvey, ConveyEnvironment, MessagePriority

# Synchronous Client
client = Convey(
    api_key="sk_live_...",
    environment=ConveyEnvironment.PRODUCTION,
    rate_limiter={"requests_per_second": 50, "burst": 10},
)

# Fluent Message Builder
res = (
    client.message()
    .to("user@example.com")
    .email(subject="Security Alert", html="<p>New login detected</p>")
    .priority(MessagePriority.CRITICAL)
    .send()
)

# Lifecycle Polling
delivered = client.messages.wait_for_delivery(res.public_id, timeout_s=30.0)
print(f"Message Status: {delivered.status}")
```

### FastAPI / Starlette Webhook Integration

```python
from fastapi import FastAPI, Request
from convey import WebhookHandler

app = FastAPI()
handler = WebhookHandler(
    secret="whsec_...",
    handlers={
        "message.delivered": lambda event: print(f"Delivered: {event.id}"),
    },
)

@app.post("/api/webhooks/convey")
async def convey_webhook(request: Request):
    return await handler.handle_fastapi(request)
```

## Comprehensive Error Handling

All SDKs map HTTP and network error states into strongly-typed exceptions:

| Error Type | Trigger HTTP Status | Description |
| :--- | :--- | :--- |
| `ConveyConfigurationError` | N/A (Client-Side) | Missing or invalid `baseUrl` / `environment` |
| `ConveyValidationError` | HTTP 400 | Invalid payload, missing required schema fields |
| `ConveyAuthenticationError` | HTTP 401 | Invalid or expired API Key |
| `ConveyForbiddenError` | HTTP 403 | Tenant permissions or quota boundary exceeded |
| `ConveyNotFoundError` | HTTP 404 | Entity or message ID not found |
| `ConveyConflictError` | HTTP 409 | Idempotency key payload mismatch |
| `ConveyRateLimitError` | HTTP 429 | Rate limit exceeded (`Retry-After` seconds exposed) |
| `ConveyTimeoutError` | N/A | Request exceeded configured timeout deadline |
| `ConveyNetworkError` | N/A | DNS resolution failure or socket reset |
| `ConveySecurityError` | N/A | Webhook HMAC-SHA256 signature verification failure |
